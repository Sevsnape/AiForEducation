# 文件对话与文件出题

> 状态：产品设计 + 前端 Mock（2026-08-12）  
> SQL：[sql/005_uploads.sql](./sql/005_uploads.sql)  
> 关联：[系统设计草案.md](./系统设计草案.md)、[LangGraph框架思路.md](./LangGraph框架思路.md)

## 1. 目标

1. **老师出题台**：支持上传讲义 / 试卷 / 习题扫描件，**按文件（或文件+知识点）出题**  
2. **常规对话**（学生 / 老师助手）：支持在消息中**附加文件**，基于材料讲解、练习、出题或答疑  

对象存储存文件本体；业务库只存元数据与抽取引用。图 State **不塞全文**，按需用 `file_id` / `extract_text_ref` 注入切片。

## 2. 产品能力

### 2.1 出题台 `/teacher/studio`

| 来源模式 | 说明 |
|----------|------|
| 按知识点 | 原有：学科 + 知识点 + 数量/难度 |
| 按文件 | 必传 ≥1 文件；可选「侧重」文案 |
| 文件 + 知识点 | 材料约束范围 + 课标知识点对齐 |

约束：

- 类型：PDF / Word / 图片 / 文本（CSV/MD/TXT）；单文件 ≤10MB；最多 5 个  
- **不读**学生 `support` / 心情原文  
- 考试级用途必须人工审题（既有政策）

### 2.2 对话附件（学生 / 老师 chat）

- 作曲器「添加文件」；可只发文件或文件+文字  
- 气泡展示附件名；counsel 会话附件 **仅学生可见**（`visibility=owner`）  
- 练习 / 出题模式可基于附件生成练习卡 / 题包（Mock 已示意）

### 2.3 教师：题包可追溯（助手 ↔ 出题台）

核心对象是**题包（Question Pack）**，不是把聊天正文强行塞进出台参数。

| 能力 | 说明 |
|------|------|
| 生成并归档 | 出题台生成后写入题包库（v1） |
| 添加到对话 | 把当前题包带入助手，与 AI 继续改题 |
| 存入出题台 | 对话里整理后的题集：关联题包则写**新版本**，否则新建题包 |
| 修改历史 | 同一题包多版本；可预览、恢复某一版 |

共享状态（Mock）：`AppContext.questionPacks` / `chatPackId`。后端可落 `artifacts` + `artifact_versions`。

约束：仍不读学生 `support` / 心情原文。

## 3. 数据模型

见 `uploaded_files`、`artifact_source_files`。

| 字段要点 | 含义 |
|----------|------|
| `purpose` | `chat` / `question_gen` / `practice` |
| `storage_key` | 对象存储键 |
| `extract_status` | pending → ready / failed |
| `visibility` | counsel 强制 `owner` |

## 4. Agent / 工具（后端落地）

| 步骤 | 说明 |
|------|------|
| 上传 API | `POST /files` → 元数据 + 预签名 PUT |
| 抽取 | 异步 OCR/解析 → `extract_text_ref` |
| 出题 | `question_gen` 读取文件切片 + 可选知识点；写入 `artifacts` + `artifact_source_files` |
| 对话 | `load_context` 注入当回合附件摘要；counsel 路径禁止外泄给老师视图 |

工具草案：`fetch_file_extract(file_id)`、`search_in_upload(file_id, query)`。

## 6. 逻辑 API

```text
POST   /files                     # 创建上传意图 / 元数据
PUT    /files/{id}/content        # 或预签名直传
GET    /files/{id}                # 元数据（鉴权）
DELETE /files/{id}

POST   /teacher/question-gen      # body: { source: knowledge|file|mixed, file_ids[], ... }
POST   /agent/chat                # multipart 或 file_ids[] 与文本同发
```
