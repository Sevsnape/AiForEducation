# 学情分析与问题模块

> 状态：产品 + 后端 Phase 2 增补（2026-08-10）  
> 关联：[三角色与管理后台.md](./三角色与管理后台.md)、[数据库表结构.md](./数据库表结构.md)、[sql/003_question_asks.sql](./sql/003_question_asks.sql)

## 1. 目标

在**不触碰心理/支持原文**的前提下：

1. **记录学生学业提问**，并打上知识点/模块标签  
2. **整体视角**：哪些模块被问得最多、覆盖多少学生（班级 / 校级热点）  
3. **个人视角**：每个学生常问哪些模块、提问次数与占比  

用于管理员学情分析、教师班级教学反馈；与 `learning_events`（答题对错）互补：前者偏「问什么」，后者偏「练得怎样」。

## 2. 数据边界（硬规则）

| 可写入 / 可展示 | 禁止 |
|-----------------|------|
| intent ∈ `practice` / `question_gen` / `diagnose` / `general` | `counsel` / `safety` 回合 |
| `module_tag`、学科、截断后的 `question_preview` | 情绪原文、`support_json` |
| 班级/组织聚合统计 | 把支持侧摘要混进热点榜 |

老师查看班级热点仍受 `share_learning_with_teacher` 与班级 `memberships` 约束（API 落地时校验）；管理员看校级聚合需记 `audit_logs`。

## 3. 表：`question_asks`

见 [sql/003_question_asks.sql](./sql/003_question_asks.sql)。

关键字段：`student_id`、`module_tag`、`intent`、`question_preview`、`org_id`、`class_id`、`thread_id`、`message_id`。

与 `learning_events` 分工：

| 表 | 回答的问题 |
|----|------------|
| `question_asks` | 学生**问了**哪些模块 |
| `learning_events` | 学生**答了**哪些题、对错与难度 |

## 4. 后端实现

| 组件 | 路径 | 职责 |
|------|------|------|
| 模块打标 | `domain/services/module_tags.py` | 启发式别名匹配（可替换为 LLM/词表服务） |
| 分析服务 | `domain/services/analytics_service.py` | 写入提问、模块热点、学生分布、`overview` |
| 内存存储 | `memory_store.question_asks` | Phase 1/2 内存；对齐 SQL |
| 持久化节点 | `agent/nodes/persist.py` | 学习意图回合自动 `record_ask_from_turn` |
| ORM | `infra/db/models.QuestionAsk` | 与 003 脚本对齐 |
| CLI | `aiforec analytics` | 打印热点 / 学生分布 |

示例：

```bash
aiforec analytics
aiforec analytics --student-id u-s1
aiforec analytics --class-id class-2-3
```

## 5. 前端

| 入口 | 说明 |
|------|------|
| `/admin/analytics` | 管理后台「学情分析」：整体热点 + 学生提问分布 |
| `/teacher/class` | 班级学情侧栏展示模块热点摘要 |
| 管理导航 | **左侧侧边栏**（用户 / 组织 / 学情分析 / 审计） |

前端当前为 Mock，数据与后端 demo seed 对齐。

## 6. 逻辑 API（后续 HTTP）

```text
GET  /admin/analytics/overview?org_id=&class_id=
GET  /admin/analytics/students/{id}/modules
GET  /teacher/classes/{id}/module-hotspots   # 需同意与班级关系
POST （由 agent persist 内部写入，不对外暴露原文上报）
```

响应仅含聚合字段与脱敏 preview，不返回 counsel 消息。
