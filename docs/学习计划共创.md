# 学习计划共创

> 状态：产品 + 后端骨架（2026-08-10）  
> 关联：[系统设计草案.md](./系统设计草案.md)、[LangGraph框架思路.md](./LangGraph框架思路.md)、[sql/004_learning_plans.sql](./sql/004_learning_plans.sql)

## 1. 目标

学生可以在对话中与 AI **一起制定、修订自己的学习计划**（目标、时间跨度、每日/每周步骤、聚焦模块），而不是只改「近期目标」一句话。

计划属于**学习侧**：可授权给老师看摘要；**不包含**心情/支持原文。

## 2. 用户流程（学生）

1. 对话页选择模式「学习计划」，或自然语言说「帮我定两周复习计划」  
2. AI 根据画像薄弱点、可用时间与学生补充，给出结构化草稿  
3. 学生继续对话修改（天数、模块、强度）  
4. 确认后写入 `learning_plans`，并在「我的」页展示  
5. 后续练习/出题可引用当前 `active` 计划（二期）

高风险（`risk=high`）时：**不生成加压刷题型计划**，走安全回复。

## 3. 数据：`learning_plans`

见 [sql/004_learning_plans.sql](./sql/004_learning_plans.sql)。

`content_json` 建议字段：

```json
{
  "goals": ["..."],
  "steps": ["..."],
  "focus_modules": ["二次函数"],
  "notes": "可选备注"
}
```

状态：`draft` → `active` → `completed` / `archived`。

## 4. Agent

| 项 | 说明 |
|----|------|
| Intent / ClientMode | `study_plan` |
| 专家节点 | `agent/experts/study_plan.py` |
| 路由 | 显式模式或关键词（学习计划/定计划/周计划…） |
| 持久化 | `persist_turn` 在 `response_payload.type=study_plan` 时 `save_study_plan` |
| 老师 | 默认不进共创计划对话（路由回出题）；只读授权学情摘要时可看计划摘要（API 二期） |

## 5. 前端

| 位置 | 行为 |
|------|------|
| 对话 `ModeChips` | 「学习计划」模式 |
| 气泡 payload | `type: study_plan` 展示目标与步骤 |
| 「我的」 | 展示当前计划 + CTA「和 AI 一起定计划」 |

## 6. 逻辑 API（后续）

```text
GET  /me/study-plan

POST /agent/chat  mode=study_plan # 共创写入由 graph persist

```
