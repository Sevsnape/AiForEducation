# 学生历史管理

> 状态：产品 + 前端 Mock（2026-08-12）  
> 关联：[系统设计草案.md](./系统设计草案.md) 第 6 章、表 `threads` / `messages` / `weekly_summaries`

## 1. 定位

`/student/history` 不只是只读回顾，而是学生侧的**历史管理工作台**：

1. **对话管理**：检索、筛选、置顶、重命名、归档、批量删除、打开续聊  
2. **成长总结管理**：按**多阶段**（如每周）查看，而非单一「本周」卡片；可归档、恢复、触发重生成，并对比相邻阶段学习指标  
3. **AI 记得你**：长期印象（删除大量历史后可能重摘要）

卡片视觉可保持现有 surface 风格；重点补齐管理能力。

## 2. Tab A · 对话

| 能力 | 说明 |
|------|------|
| 搜索 | 标题 / 预览 |
| 筛选 | 意图类型、进行中 / 归档 / 全部 |
| 置顶 | 列表优先排序 |
| 重命名 | 学生可改自动标题 |
| 打开 | 进入对话页续聊（后端加载消息） |
| 归档 / 恢复 | 软隐藏，不立刻物理删 |
| 删除 | 硬删；触发 `needs_resummary` |
| 批量 | 多选归档 / 恢复 / 删除 |
| 隐私 | `counsel` 会话「仅你可见」标记 |

列表字段扩展：`messageCount`、`pinned`、`status`、`lastActiveDate`。

## 3. Tab B · 成长总结（多阶段）

成长是**阶段序列**（对应 `weekly_summaries` 多行：`week_start` 唯一），不是单页三个卡片。

| 能力 | 说明 |
|------|------|
| 阶段列表 | 当前 / 过往 / 已归档 |
| 详情 | 学习侧、支持侧（仅学生）、下一步 |
| 指标 | 练习题量、正确率、聚焦模块 |
| 归档本阶段 | 不删数据，列表默认折叠 |
| 重新生成 | 调 summary 流水线重算该周 |
| 对比 | 相邻阶段学习侧题量/正确率表（不含 support 原文） |

生成频率：周期自动 + 学生手动「重新生成」。
