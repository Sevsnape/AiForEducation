# 同意策略（管理员配置）

> 状态：MVP 约定（2026-08-12 更新：按班级分类）  
> 关联：[三角色与管理后台.md](./三角色与管理后台.md)、表 `consents`

## 结论

**同意设置暂不开放给学生端自助修改**，由**管理员**在管理后台统一配置。

层级（由宽到窄）：

1. **校级默认策略**（新建学生 / 无覆盖时生效）  
2. **班级模板**（按班级批量应用到该班学生）  
3. **学生级覆盖**（个别微调）

学生「我的」页仅提示：策略由学校管理员配置；如需调整请联系管理员。

## 字段含义（不变）

| 开关 | 含义 |
|------|------|
| `learning_personalize` | 是否用学习画像个性化练习/出题 |
| `history_retain` | 是否留存会话历史 |
| `share_learning_with_teacher` | 是否把学习侧学情共享给授权老师（support 仍不可见） |

## 前端

- 路由：`/admin/consents`  
- 侧栏：「同意设置」  
- **按班级筛选**（全部 / 各班）  
- **按班级分组**：班级模板 + 本班学生表；可折叠；「应用到本班」批量写入  

变更建议写入 `audit_logs`（HTTP API 落地时）。班级模板可后续落库为 `consents.org_id + class_id` 作用域。
