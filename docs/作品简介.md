## 作品简介正文（500 字以内，可整段粘贴）

AIFOREC 面向智慧教育，定位为学生中心的学业支持 AI：服务中小学生学习巩固与学业情绪支持，并协助教师出题与查看授权学情，学校侧可做账号、同意与学情治理。针对辅导与心理混谈、出题难贴合薄弱点与教材材料、学情难合规汇总、情绪数据易被误用等问题，以 LangGraph 多智能体完成门禁、风险识别与意图路由：出题、练习、学习计划共创与情绪支持分流；高风险时切断加压刷题并提示求助。系统维护学习/支持双域可纠正画像、多阶段成长总结与对话历史管理；学业提问沉淀为模块热点与个人分布，供管理分析与班级学情（不含心理原文）。教师可按知识点或上传讲义试卷出题；师生对话均可附文件。同意策略由管理员按校级与班级配置，老师默认不可见支持侧。创新在于学生主视角、双域隔离、风险与练习硬隔离、文件增强教学与可落地的表结构及 Agent 契约。已完成设计文档、SQL、可运行后端骨架与三角色前端演示；下一步接入大模型、对象存储与完整数据层。
