## 作品简介正文（500 字以内，可整段粘贴）

AIFOREC 面向智慧教育场景，定位为「以学生为中心」的学业支持 AI：服务中小学生学习巩固与学业情绪支持，并协助教师出题与查看授权范围内学情。核心问题在于：刷题辅导与心理支持常混在同一对话中，边界不清；教师出题与个性化巩固缺少连贯学情；涉及情绪的数据若对教师透明，既不合规也伤害信任。本作品以 LangGraph 搭建多智能体编排：安全门禁与风险识别后，按意图路由至出题、练习巩固或学业情绪支持等专家路径；高风险时切断加压刷题并给出求助指引。系统为每位学生维护可纠正的长期画像（学习侧 / 支持侧分离）与会话历史总结，形成「专属支持」体验，而非一人一常驻进程。权责上明确同意开关与审计：教师默认可协作出题与看学业结果，不可查看心理原文与支持侧摘要。创新点在于学生主视角、教学—支持双域隔离、风险与练习链路硬隔离，以及可落地的数据表与 Agent 状态契约。开放复用上，主图路由、可见性策略与 PostgreSQL 表结构可迁移至校本助手等同类系统。当前已完成系统设计文档、数据库脚本注释与可运行的 LangGraph 后端骨架（规则路由与专家占位，测试通过）；下一步将接入大模型、落地 SQL 仓储与学生历史能力。

## 更短版（约 250 字，若栏位更紧）

AIFOREC 是面向智慧教育的学生中心学业支持系统：用 LangGraph 多智能体完成出题、巩固练习与学业情绪支持分流，并以学习/支持双域画像与历史总结形成专属支持；教师可协作教学，但默认不可见心理内容。针对辅导与心理边界不清、个性化不足、隐私风险等问题，引入风险短路、同意与审计机制。已完成架构文档、SQL 与可运行后端骨架，待接大模型与完整数据层。
